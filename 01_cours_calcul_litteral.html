Calcul littéral

Développer, réduire, factoriser : trois gestes, un même rectangle.

Objectifs et compétences

  • Calculer une expression pour un nombre donné.
  • Développer et réduire une expression.
  • Factoriser par un facteur commun.
  • Reconnaître a² − b² et (a + b)².

Compétences travaillées

CalculerReprésenterRaisonnerCommuniquer

Code couleur : x² · x · nombres · facteur commun

1Une lettre pour un nombre

3x veut dire 3 × x. On peut remplacer x par n’importe quel nombre.

À toi : choisis x

−2
Piège : (−3)² = 9, mais sans parenthèses la calculatrice lit −3² = −9.

2Réduire : ranger par familles

On additionne seulement des termes de la même famille.

2x² + 4x² = 6x², mais x² + x ne se simplifie pas.

3Développer : la simple distributivité

Le nombre devant la parenthèse multiplie chaque terme.

k(a + b) = ka + kb     k(a − b) = ka − kb
Développer, c’est transformer un produit en somme.

4Le piège du signe moins

Un moins devant une parenthèse retourne tous les signes.

−(a + b) = −a − b     −(a − b) = −a + b
Erreur fréquente : changer le signe du premier terme et oublier le second.

5La double distributivité

Chaque terme de la 1re parenthèse multiplie chaque terme de la 2e.

(a + b)(c + d) = ac + ad + bc + bd

Simulateur : (x + a)(x + b)

2 3
4

6Le carré d’une somme

(x + 3)² veut dire (x + 3)(x + 3) : quatre cases, pas deux.

(a + b)² = a² + 2ab + b²     (a − b)² = a² − 2ab + b²
Piège : (x + 3)² n’est pas x² + 9. Le double produit 6x manque.

7Factoriser : le chemin retour

On repère le facteur commun et on recolle les rectangles.

MÉTHODE — factoriser
  1. Repérer le facteur présent dans chaque terme.
  2. L’écrire devant, ce qui reste va dans la parenthèse.
  3. Vérifier en redéveloppant.
10x² − 15x = 5x(2x − 3) : on prend le plus grand facteur commun.

8Une différence de deux carrés

On découpe le carré, on déplace la bande : un rectangle apparaît.

a² − b² = (a + b)(a − b)
x² − 49 = (x + 7)(x − 7)  ·  9x² − 4 = (3x + 2)(3x − 2)

9Vérifier avec un nombre

Deux écritures égales donnent le même résultat pour tout x.

Le vérificateur : compare deux écritures

Sept questions. Une seule bonne réponse par question.

À retenir

Développer : produit → somme. Factoriser : somme → produit.
Réduire : regrouper les x², les x et les nombres.
Un moins devant une parenthèse change tous les signes.
Toujours vérifier avec un nombre simple, comme x = 2.

Trace écrite

À recopier dans le cahier.

Développer, c’est transformer un produit en somme.

k(a + b) = ka + kb    (a + b)(c + d) = ac + ad + bc + bd

Réduire, c’est regrouper les termes de la même famille.

Un signe − devant une parenthèse change le signe de chaque terme.

Factoriser, c’est transformer une somme en produit.

ka + kb = k(a + b)    a² − b² = (a + b)(a − b)

(a + b)² = a² + 2ab + b²

Pour vérifier, on remplace x par un nombre dans les deux écritures.
