Table générée depuis les fichiers eux-mêmes : constante `CODE` de chaque jeu, croisée avec le code
affiché en fin de TP. Contrôle passé : 70 jeux sur 70 rattachés à une séquence, aucune incohérence
entre le code délivré et le code attendu.
